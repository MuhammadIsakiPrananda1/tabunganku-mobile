# 🚀 TabunganKu Versi 1.4.7

Rilis **v1.4.7** memprioritaskan stabilitas sistem dengan mengatasi tuntas kendala layout rendering dashboard (*Zero-Crash Engine*), menyempurnakan algoritma penataan label grafik donat agar tidak tumpang tindih, dan merapikan kisi-kisi lencana prestasi.

---

### 🆕 Fitur Yang Ditambah (What's New)

#### 🛡️ Zero-Crash Dashboard Engine
* **Penyelesaian Kendala RenderBox**: Mengeliminasi 100% pengecualian *"RenderBox was not laid out"* pada dashboard ringkasan alokasi dana, menjamin pengalaman bebas crash pada segala skenario orientasi layar.

#### 🍩 Optimalisasi Grafik Donat FL Chart
* **Algoritma Anti-Overlap Teks**: Label persentase kategori kecil secara otomatis diatur posisinya secara radial sehingga tidak pernah saling menumpuk.

---

### 🛠️ Fitur Yang Diubah & Ditingkatkan (Improvements)
* **Responsivitas Grid Lencana**: Koleksi medali kedisiplinan keuangan tertata rapi dan proporsional di semua resolusi layar smartphone.
* **Penyelarasan Dokumentasi README**: Desain visual banner dan lencana status proyek dirapikan agar tampak profesional.

---

### ⚡ Detail Teknis Rilis
* **Build**: v1.4.7-stable
* **Android Split APK**: arm64-v8a, armeabi-v7a, x86_64
